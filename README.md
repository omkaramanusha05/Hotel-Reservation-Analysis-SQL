# Hotel Reservation Analysis using SQL

## Project Overview
This project focuses on analyzing hotel reservation data using MySQL to understand booking trends, guest booking behaviour, hotel performance, and stay outcomes.

## Tools Used
- MySQL
- SQL

## Database Tables
- Hotels
- Guests
- Bookings
- Rooms
- Staff
- Stays

## Project Objectives
- Analyze hotel booking demand and booking channels.
- Identify popular room types and hotels.
- Understand guest booking behaviour and booking revenue.
- Evaluate stay status and average stay duration.
- Analyze staff performance and room utilization.
- Identify cancellations, no-shows, and service-request patterns.

## SQL Concepts Used
- Database and table creation
- SELECT and DISTINCT
- WHERE and ORDER BY
- GROUP BY and aggregate functions
- JOIN operations
- CASE statements
- Date functions
- LIMIT

## Project File
`SQL-project1.sql` — Contains the database setup, table creation statements, and SQL analysis queries.
